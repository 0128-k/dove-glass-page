# 鸽子 · Glass Atelier

玻璃拟态（Glassmorphism）风格的陪玩接单主页，**单文件 HTML** —— 音频、粒子动画、交互全部内联，无需构建。

## 特性

- 开场星尘粒子交互动画（轻触任意处进入）
- 紫蓝极光光斑缓慢移动 + 半透明磨砂玻璃卡片
- 标题微发光、玻璃质感按钮
- 内置氛围背景音（32 秒无缝循环）与清脆触发音（Web Audio 合成，带程序化兜底）
- 技能报价弹窗 / 资料跳转 / 所属团身份 / 下单须知 / 联系方式

## 使用

直接用浏览器打开 `index.html` 即可，或访问 GitHub Pages 地址。

> 首次进入需要点击一次页面，浏览器才允许播放声音。

## 技术

纯原生 HTML + CSS + JavaScript，无外部依赖、无外链资源。
